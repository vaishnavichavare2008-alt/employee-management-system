# Employee Management System

A simple Employee Management System developed using Python, Streamlit and SQLite.

## Features

- Dashboard
- Add Employee
- View Employees
- Search Employees
- Update Employee
- Delete Employee
- Employee statistics
- SQLite database

## Run Locally

1. Install Python.
2. Open this project folder in VS Code.
3. Open the VS Code terminal.
4. Run:

```bash
pip install -r requirements.txt
```

5. Start the application:

```bash
streamlit run app.py
```

The `employee.db` database file is created automatically when the application starts.

## Deployment

This project can be deployed as a Streamlit application using a GitHub repository.
